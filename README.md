# AVANGARD SHOP

Навчальний сайт магазину комп’ютерної техніки. Лабораторна робота №4 (Flask, SQLite).

## Опис

AVANGARD SHOP — вебмагазин із каталогом ноутбуків, стаціонарних комп’ютерів і приставок. Покупець може шукати й фільтрувати товари, додавати їх до кошика та оформлювати замовлення. Дані товарів, клієнтів, відгуків і замовлень зберігаються в SQLite.

## Сторінки та функції

- **Головна** — банер магазину й переходи до категорій техніки.
- **Каталог** — перегляд товарів, пошук за назвою та фільтр за категорією.
- **Категорії** — ноутбуки, стаціонарні комп’ютери та приставки.
- **Кошик** — зміна кількості товарів, видалення позицій та оформлення замовлення.
- **Промокоди** — застосування знижки під час оформлення замовлення.
- **Про нас** — інформація про магазин.
- **Зворотний зв’язок** — форма надсилання повідомлення.
- **Адмін-панель** — перегляд і зміна статусів замовлень, перегляд та редагування відгуків, керування товарами, клієнтами й промокодами.

## База даних

Застосунок використовує SQLite. Таблиці проєкту:

- `products` — товари каталогу;
- `clients` — клієнти магазину;
- `feedback` — повідомлення з форми зворотного зв’язку;
- `orders` — оформлені замовлення та їхні статуси;
- `order_items` — товари й кількість у кожному замовленні;
- `promo_codes` — коди знижок.

Таблиці `orders` і `products` мають зв’язок «багато-до-багатьох» через `order_items`. Ціни в замовленні зберігаються на момент покупки. Під час запуску застосунок створює відсутні таблиці та додає початкові товари, яких ще немає в каталозі. З’єднання з базою закривається після запиту, зовнішні ключі SQLite ввімкнені, а значення SQL-запитів передаються параметрами.

## Запуск проєкту

1. Клонуйте репозиторій:

```bash
git clone https://github.com/The-Avangard/Lab-04.git
cd Lab-04
```

2. Створіть і активуйте віртуальне середовище:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

3. Встановіть залежності:

```bash
pip install -r requirements.txt
```

4. Запустіть застосунок:

```bash
python app.py
```

Відкрийте сайт за адресою <http://127.0.0.1:5000/>. База даних ініціалізується автоматично під час запуску.
